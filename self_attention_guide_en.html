Step 01 · Background

1. Why Attention Was Invented: Focusing on What Matters

When humans read or translate a long sentence, we do not give equal mental effort to every single word. Instead, we focus our attention on the key words that carry the core meaning while skimming supporting words.

Early neural machine translation relied on Encoder–Decoder Recurrent Neural Networks (Seq2Seq), which suffered from two major bottlenecks:

  • Information Bottleneck: The Encoder read the entire source sentence sequentially and compressed all of its meaning into a single fixed-size context vector. For long sentences, early information was easily lost.
  • Sequential Computation: Because RNNs process tokens one by one, computation could not be parallelized across time steps.
Core Breakthrough: Look Back at All Encoder States Directly Instead of forcing the Decoder to rely solely on one compressed final vector, the Attention mechanism allows the Decoder at each output step to inspect all Encoder hidden states and assign higher weights to the source words most relevant to the word currently being generated.
Step 02 · Self-Attention

2. From Attention to Self-Attention: Finding Internal Context

While classic Attention measures alignment between an output sequence (Decoder) and an input sequence (Encoder), Self-Attention measures relationships among words within the same sequence. Introduced in the Transformer architecture (Vaswani et al., 2017), Self-Attention eliminates recurrence entirely and models dependencies directly across any distance.

Context Resolution Example: What Does "it" Refer To?
  • Sentence A: "The animal didn't cross the street because it was too tired." → it strongly attends to animal.
  • Sentence B: "The animal didn't cross the street because it was too wide." → it strongly attends to street.
Self-Attention computes pairwise relevance scores across all tokens in the sentence so that each token's representation absorbs surrounding context.
Step 03 · Architecture & Dimensions

3. Position in the Network, Embedding ($d_{\text{model}}$) & Projection ($d_k, d_v$)

1) A Learnable Layer Inside the Network (Not Pre-Analysis)

Self-Attention is not an external statistical pre-processing step performed before feeding data into a neural network. Rather, it is a core learnable layer inside the network trained end-to-end via backpropagation. It produces a context-enriched matrix $Z$ and passes it directly into position-wise MLP (Feed-Forward Network) layers.

2) What Is the Input Embedding Dimension ($d_{\text{model}}$)?

Instead of representing each word as a single scalar number, neural networks map each token to a dense feature vector of length $d_{\text{model}}$. For a sequence of length $L$ with $d_{\text{model}} = 512$, the input matrix has shape:

$$X \in \mathbb{R}^{L \times d_{\text{model}}} \qquad (\text{e.g., } L=4,\; d_{\text{model}}=512)$$

A higher-dimensional space allows different axes to encode syntactic roles, tense, semantic categories, and contextual nuances simultaneously.

3) What Are the Projection Dimensions ($d_k, d_v$)?

Linear Projection multiplies the input embedding matrix $X$ by three learnable weight matrices ($W_Q, W_K, W_V$) to map tokens into specialized subspaces:

$$Q = X W_Q \in \mathbb{R}^{L \times d_k}, \qquad K = X W_K \in \mathbb{R}^{L \times d_k}, \qquad V = X W_V \in \mathbb{R}^{L \times d_v}$$ Weight shapes: $W_Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$, $W_K \in \mathbb{R}^{d_{\text{model}} \times d_k}$, $W_V \in \mathbb{R}^{d_{\text{model}} \times d_v}$

Because $Q, K,$ and $V$ all originate from the same input sequence $X$, the mechanism is called Self-Attention. Multiplying by distinct matrices $W_Q, W_K, W_V$ allows each representation to play a distinct functional role.

Step 04 · Intuition & Geometry

4. Intuitive Analogies & Asymmetry of Query, Key, and Value

Everyday Analogy: Hotel Check-In / Database Retrieval
  • Query ($Q$): Walking up to the hotel reception desk and asking, "I booked Room 512—how do I get in?" (your search request).
  • Key ($K$): The receptionist matching your request against the registry and handing you the room key (the indexing label).
  • Value ($V$): Unlocking the door and accessing the actual contents inside the room (the information payload retrieved).

Why Does Query Represent "What Position $i$ Is Searching For"?

This specialization is not manually programmed; it emerges naturally from the geometry of the inner product and gradient-based learning:

$$\text{score}(i, j) = q_i k_j^\top = \sum_{m=1}^{d_k} q_{i, m} \, k_{j, m}$$
  • Dot-Product Alignment: Two vectors yield a large inner product when they share large values of the same sign along corresponding coordinates $m$. If token $j$ ("animal") produces a key $k_j$ with a strong activation on axis 3 indicating "animate subject", and token $i$ ("it") needs an antecedent to minimize prediction loss, backpropagation updates $W_Q$ so that $q_i = x_i W_Q$ strongly activates axis 3.
  • Asymmetry ($W_Q \neq W_K$): If $W_Q = W_K$, then $Q = K$ and $Q Q^\top$ is strictly symmetric ($A_{i,j} = A_{j,i}$). However, natural language relationships are asymmetric: how strongly "it" attends to "animal" need not equal how strongly "animal" attends to "it". Keeping $W_Q$ and $W_K$ separate decouples the search criterion from the indexing criterion.
Step 05 · Scaled Dot-Product Attention

5. Scaled Dot-Product Attention: 4-Step Numerical Walkthrough

The core Self-Attention equation is:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V$$
1. Dot-Product Score$S = Q K^\top$
($L \times L$)
→
2. Scaling$\tilde{S} = S / \sqrt{d_k}$
Prevents saturation
→
3. Row Softmax$A = \text{softmax}(\tilde{S})$
Each row sums to 1
→
4. Value Aggregation$Z = A V$
($L \times d_v$)

Let us trace a concrete numerical example with sequence length $L=3$ and projection dimensions $d_k = 2, d_v = 2$:

$$Q = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{bmatrix}, \qquad K = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 0 \end{bmatrix}, \qquad V = \begin{bmatrix} 2 & 0 \\ 0 & 4 \\ 1 & 2 \end{bmatrix}$$
  1. Step 1 — Raw Attention Scores ($S = Q K^\top \in \mathbb{R}^{3 \times 3}$):
    Compute the dot product between every query row $i$ and every key row $j$.
    $$S = Q K^\top = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{bmatrix} \begin{bmatrix} 1 & 0 & 1 \\ 0 & 1 & 0 \end{bmatrix} = \begin{bmatrix} 1 & 0 & 1 \\ 0 & 1 & 0 \\ 1 & 1 & 1 \end{bmatrix}$$
  2. Step 2 — Scaling by $\sqrt{d_k}$ ($\tilde{S} = \dfrac{S}{\sqrt{2}}$, where $\sqrt{2} \approx 1.414$):
    As $d_k$ grows large, dot products grow in variance, pushing Softmax into regions with extremely small gradients (vanishing gradients). Dividing by $\sqrt{d_k}$ keeps the variance around 1.
    $$\tilde{S} = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 & 0 & 1 \\ 0 & 1 & 0 \\ 1 & 1 & 1 \end{bmatrix} \approx \begin{bmatrix} 0.707 & 0 & 0.707 \\ 0 & 0.707 & 0 \\ 0.707 & 0.707 & 0.707 \end{bmatrix}$$
  3. Step 3 — Row-Wise Softmax ($A = \text{softmax}(\tilde{S}) \in \mathbb{R}^{3 \times 3}$):
    Softmax converts each row into a probability distribution of non-negative weights summing to $1.0$. Row $i$ specifies how position $i$ allocates 100% of its attention across positions $1, 2,$ and $3$.
    • Row 1 ($\exp(0.707) \approx 2.028$, $\exp(0) = 1.0$, sum $\approx 5.056$): $[0.401,\; 0.198,\; 0.401]$
    • Row 2 ($\exp(0) = 1.0$, $\exp(0.707) \approx 2.028$, sum $\approx 4.028$): $[0.248,\; 0.504,\; 0.248]$
    • Row 3 (all entries equal to $0.707$): $[0.333,\; 0.333,\; 0.333]$
    $$A \approx \begin{bmatrix} 0.401 & 0.198 & 0.401 \\ 0.248 & 0.504 & 0.248 \\ 0.333 & 0.333 & 0.333 \end{bmatrix}$$
  4. Step 4 — Weighted Sum of Values ($Z = A V \in \mathbb{R}^{3 \times 2}$):
    Multiply the attention weight matrix $A$ by $V$ to aggregate context. For instance, the top-left entry is $0.401 \times 2 + 0.198 \times 0 + 0.401 \times 1 \approx 1.203$.
    $$Z = A V \approx \begin{bmatrix} 0.401 & 0.198 & 0.401 \\ 0.248 & 0.504 & 0.248 \\ 0.333 & 0.333 & 0.333 \end{bmatrix} \begin{bmatrix} 2 & 0 \\ 0 & 4 \\ 1 & 2 \end{bmatrix} \approx \begin{bmatrix} 1.203 & 1.594 \\ 0.744 & 2.512 \\ 1.000 & 2.000 \end{bmatrix}$$
Matrix Shape Interpretation
Attention Matrix $A$ $L \times L$ ($3 \times 3$) Row-stochastic weight table where each row sums to $1$. Entry $A_{i,j}$ indicates how much position $i$ attends to position $j$.
Output Matrix $Z$ $L \times d_v$ ($3 \times 2$) Preserves sequence length $L$, updating every token into a context-aware representation.
Step 06 · Multi-Head Attention

6. Multi-Head Attention: Parallel Perspectives

Rather than performing a single attention pass, Transformers split the representations into $h$ parallel attention heads—a mechanism called Multi-Head Attention.

Intuitive Analogy: A Team Brainstorming Session Analyzing a sentence with a single head can over-focus on one aspect (such as grammatical verb agreement). With 8 heads working in parallel, different heads can specialize in different relationships simultaneously—such as pronoun coreference, tense, modifier attachment, and semantic similarity—and combine their findings afterward.
  • Split & Parallelize: With $d_{\text{model}} = 512$ and $h = 8$ heads, each head projects into $d_k = d_v = 512 / 8 = 64$ dimensions and computes $\text{head}_i \in \mathbb{R}^{L \times 64}$ independently.
  • Concatenate & Fuse: All 8 head outputs are concatenated back into $\mathbb{R}^{L \times 512}$ and passed through a final linear projection $W_O \in \mathbb{R}^{512 \times 512}$:
    $$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W_O$$
Step 07 · Positional Encoding

7. Positional Encoding: Injecting Order into Parallel Processing

Because the Transformer processes the entire sequence matrix $X$ in parallel rather than step-by-step like an RNN, dot-product attention alone has no built-in awareness of word order.

Example: "The dog chased the cat" and "The cat chased the dog" have opposite meanings, yet without positional cues, Self-Attention treats them as identical sets of tokens.

To inject sequence order, a Positional Encoding vector is added to each token's input embedding before the first layer, using sinusoidal functions of different frequencies:

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right), \qquad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right)$$
  • Why Sinusoids Instead of Raw Integers ($1, 2, 3, \dots$)? Raw integers grow unboundedly for long sequences and destabilize training. Sine and cosine values stay bounded within $[-1, 1]$ regardless of sequence length and allow the model to represent relative token offsets cleanly via linear transformations.
Step 08 · Training & LLM Workflow

8. Backpropagation Training & Full LLM Workflow

1) How Are $W_Q, W_K, W_V$ Learned?

$Q, K,$ and $V$ are never hand-crafted. Instead, $W_Q, W_K, W_V$ are randomly initialized and updated via gradient descent to minimize prediction loss:

  1. Forward Pass: Compute $Q = XW_Q$, $K = XW_K$, $V = XW_V$, and $Z = AV$.
  2. Loss Evaluation: Pass $Z$ through downstream MLP (FFN) and output layers to generate predictions $\hat{Y}$ and compute task loss $\mathcal{L}(\hat{Y}, Y)$.
  3. Backpropagation & Update: Compute gradients via the chain rule and update parameters:
    $$W_Q \leftarrow W_Q - \eta \frac{\partial \mathcal{L}}{\partial W_Q}, \qquad W_K \leftarrow W_K - \eta \frac{\partial \mathcal{L}}{\partial W_K}, \qquad W_V \leftarrow W_V - \eta \frac{\partial \mathcal{L}}{\partial W_V}$$
